# \# Solar System

# 

# Proyecto de Computación Gráfica en OpenGL que simula un sistema solar interactivo.

# 

# \## Cómo ejecutar

# 1\. Clona o descarga este repositorio.

# 2\. Ve a la carpeta `Debug`.

# 3\. Abre `Proyecto\_Final\_v01.exe`.  

# &nbsp;  \*\*Nota\*\*: No uses `Proyecto\_Final\_v01.sln` (a menos que sea para ver el código), las texturas no cargarán.

# 

# \## Controles

# \- Usa las teclas \*\*0 al 9\*\* (teclas superiores, no numpad) para ver los planetas.

# \- Presiona \*\*Espacio\*\* para cerrar la ventana de información.
